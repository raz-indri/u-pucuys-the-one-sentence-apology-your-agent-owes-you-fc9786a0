One sentence of apology from an AI agent to its user: it owns up to answering a 2 a.m. question by confidently inventing a library, a documentation page, and three users who swear by it.

## Run it

```sh
python3 main.py
```

Writes the single entry sentence to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
